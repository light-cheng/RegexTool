# 03 — ISO/IEC 15424 AIM ID 码制前缀智能探测与双模式候选生成

**What to build:** 自动识别扫码设备输出的 3 字节 ISO/IEC 15424 AIM ID 码制前缀（如 `]d1`, `]d6`, `]C1`, `]Q1` 等）。在候选列表中同时提供「剥离 AIM ID（标准载荷）」与「保留 AIM ID（全链路路由）」两种变体；界面分段表中将 AIM ID 分段明确标识为 `[AIM Prefix]`，供工程师根据上位机架构灵活选用。

**Blocked by:** 01 — 智能变长归纳与抗过拟合对齐

**Status:** done

- [x] 输入带 `]d1` 或 `]d6` 等 AIM ID 前缀的正例样本时，工具自动探测到码制前缀，并在分段列表中将首段标记为 `[AIM Prefix]`
- [x] 生成结果中同时产出剥离前缀的纯载荷正则变体（如 `^1P...$`）和包含前缀的全链路正则变体（如 `^\]d11P...$`）
- [x] 两种候选变体均能正确通过正反例验证，并支持一键复制
- [x] 核心引擎单元测试覆盖 Data Matrix (`]d1`/`]d6`)、Code 128 (`]C1`)、QR Code (`]Q1`) 等主流码制前缀测试
