# 03 — 固定标记分段与单段格式

**What to build:** 分隔符不限于标点——字母数字组成的固定标记（如 `1P`、`NQ`、`3N`）也能自动识别为分段边界并切分；只有一整段、没有任何分隔符或标记的条码，无需任何分段配置即可生成正则。分段解释必须对所有正例一致。

**Blocked by:** 01 — 最小竖切

**Status:** ready-for-agent

- [ ] 形如 `1PxxxxxxNQxxxxxx3Nxxxx`（x 为变化内容）的条码能识别 `1P`/`NQ`/`3N` 为固定标记并正确分段，固定标记在正则中原样保留
- [ ] 一整段、无分隔符无标记的条码：不配置分段也能生成正则
- [ ] 分段解释对所有正例一致
- [ ] 本票新增的引擎逻辑有单元测试覆盖（走引擎公开接口）
