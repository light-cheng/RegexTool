# 03 — Data Identifier (DI) 数据标识符前缀分段、分隔符与单段格式

**What to build:** 支持工业界（ASC MH10 / ISO/IEC 15418 / ISO/IEC 15434 / GS1）广泛使用的 Data Identifier（数据标识符 / DI，如 `1P`/`P`、`Q`、`S`、`1T`/`T`、`K`/`14K`、`4K`、`V`、`D`、`3S`/`4S` 等）前缀直连或 ISO/IEC 15434 Format 06 包络/GS（ASCII 29）控制字符分段；只有一整段、没有任何分隔符或 DI 前缀的条码，无需任何分段配置即可生成正则。分段解释必须对所有正例一致。

**Blocked by:** 01 — 最小竖切

**Status:** ready-for-agent

- [x] 形如 `1P12345678Q1001TLOT2024AS98765`（DI 前缀直连模式）或 `[)>06<GS>P...<GS>Q...` 的条码能识别 DI 前缀与分隔符并正确分段，DI 标记与分隔符在正则中原样保留
- [x] 一整段、无分隔符无标记的条码：不配置分段也能生成正则
- [x] 分段解释对所有正例一致
- [x] 本票新增的引擎逻辑有单元测试覆盖（走引擎公开接口）
