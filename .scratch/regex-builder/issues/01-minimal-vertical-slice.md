# 01 — 最小竖切（骨架 + 分隔符分段 + 单候选 + 正例验证）

**What to build:** 打通整个工具的第一条完整通路：工程能编译成单个免安装 exe（无外部依赖，UI 用 Win32 原生控件，中文界面）；正例输入区为动态添加（点「+ 正例」逐条新增、✕ 删除）；点击生成后，核心引擎按分隔符自动分段、推断段规则（固定文本原样保留、纯数字字段 `\d{n}`）、生成一个候选正则；对每条正例执行验证（整串锚定匹配 + 字段捕获值与实际值一致），界面显示正则与逐例 ✓。核心引擎保持纯逻辑、不依赖 UI，并随本票建立其单元测试框架（测试走引擎公开接口）。

**Blocked by:** None — can start immediately

## Comments

- 2026-08-17：验收锚点由用户手写目标 `SQ\d{4}` 改为如实推断输出 `SQ000\d`（SQ000 决策，选项 a）。原因：5 条正例 `SQ0001..SQ0005` 前三位 `000` 全同，引擎视为固定文本；纯数据驱动无法得知「000 是补零」。用户手写目标可由工单 05「恒定段提升为字段」达成（提升 `@SQ000` 为 `SQ` 字段后与相邻 `\d` 合并为 `SQ\d{4}`）。
