# 05 — 分段配置：长度分段 + 规则表编辑 + 恒定段提升

**What to build:** 当条码没有分隔符也没有固定标记时，用户可手动告知每段长度（如 4、4、4、2），工具按长度切分并生成对应正则；提供分段规则表，可查看并手动编辑任意一段的规则（长度、字符类型）；恒定段（如 `DT2026`，所有正例完全相同）可一键提升为字段（比如年份以后会变），提升后按字段处理而非固定文本。

**Blocked by:** 03 — 固定标记分段与单段格式

**Status:** ready-for-agent

- [ ] 按用户给定的每段长度正确切分并生成对应正则
- [ ] 分段规则表可查看并编辑每一段的规则，编辑后重新生成生效
- [ ] 恒定段可一键提升为字段，提升后该段按字段处理
- [ ] 本票新增的引擎逻辑有单元测试覆盖（走引擎公开接口）
